# 🐇 NestJS + RabbitMQ Learning Project

This repository is a **learning project** to explore **NestJS microservices** using **RabbitMQ** and sending emails via **Nodemailer**.  
It is meant for practice and understanding **event-driven architecture** in NestJS.

---

## **What I Learned**

- NestJS **controllers, modules, and providers**  
- Using **ClientProxyFactory** and `ClientProxy` to emit events  
- Listening to events with `@EventPattern` and `@Payload`  
- Connecting **NestJS to RabbitMQ** queues (`order_queue` and `payment_queue`)  
- Sending emails with **Nodemailer**  
- Using **.env** for configuration
